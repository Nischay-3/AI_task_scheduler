# AI Task Scheduler & Reminder

A simple web-based task scheduler and reminder application with AI-powered schedule optimization.

## Features

- Add tasks with title, description, and due date
- View list of tasks
- AI-powered schedule optimization using OpenAI GPT
- Browser notifications for upcoming reminders
- Local storage for persistence

## Setup

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up OpenAI API key: Create a `.env` file with `OPENAI_API_KEY=your_key_here`
4. Run the server: `npm start`
5. Open `http://localhost:3000` in your browser

## Usage

- Add tasks using the form
- Click "Optimize Schedule with AI" to get suggestions
- Allow notifications for reminders

## Technologies

- Node.js
- Express
- OpenAI API
- Vanilla JavaScript
